* **Redes y Protocolos:** Modelo OSI / TCP/IP, DNS, HTTP/S, análisis de tráfico con Wireshark y TShark.
* **Automatización y Scripts:** Python (parsers de logs, consumo de APIs), Git, GitHub y Bash.
* **Sistemas y Laboratorio:** Linux (Ubuntu Server), Windows 10, VirtualBox y simulación de ataques.
